This is a modern Spring Boot web application built using MVC architecture that allows users to explore services and connect through a validated contact form.

Features:
* Home, About & Services Pages
* Contact Form Submission
* Form Validation
* Success/Error Messages
* MySQL Database Integration
* Layered Architecture (Controller → Service → Repository)

Tech Stack:
* Java
* Spring Boot
* Spring MVC
* Spring Data JPA
* Hibernate
* ModelMapper
* JSP & JSTL
* Bootstrap
* MySQL

What I Learned ?
* MVC Architecture
* Spring Boot Development
* DTO & ModelMapper
* Bean Validation
* JPA & Hibernate
* Database Connectivity
